# Mzansi Market

Simple React/Vite project for three roles:

1. Customer
2. Product Administrator
3. Fulfilment Employee

No backend is used yet.

## Run

```bash
npm install
npm run dev
```

## Mock login

The login screen allows you to choose a role.

- Customer -> `/`
- Product Administrator -> `/admin`
- Fulfilment Employee -> `/fulfilment`

Registration creates a mock customer account only.
